# Telegram Mini App — My Mini App

## Что внутри
- Адаптивный интерфейс под телефон
- Telegram WebApp API
- Получение имени и Telegram ID пользователя
- Баланс
- Кнопки пополнения/вывода
- Быстрые действия
- Нижняя навигация

## Как запустить
Откройте `index.html` через HTTPS-хостинг (например, GitHub Pages), затем укажите URL Mini App в BotFather.

## Важно
Реальные платежи, база данных, авторизация на сервере и вывод средств пока НЕ подключены.
